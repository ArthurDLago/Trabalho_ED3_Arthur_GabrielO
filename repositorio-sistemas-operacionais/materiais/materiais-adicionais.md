# Materiais adicionais

A seleção de materiais foi atualizada para acompanhar as questões escolhidas e manter o repositório objetivo.

## 1. Bibliografia básica da disciplina

### Machado & Maia

**MACHADO, Francis B.; MAIA, Luiz Paulo. Arquitetura de Sistemas Operacionais. 4. ed. Rio de Janeiro: LTC, 2007.**

Usar como referência para arquitetura, processos, gerência e mecanismos do sistema operacional.

### Silberschatz, Galvin & Gagne

**SILBERSCHATZ, Abraham; GALVIN, Peter Baer; GAGNE, Greg. Fundamentos de Sistemas Operacionais. 8. ed. Rio de Janeiro: LTC, 2010.**

Usar principalmente para processos, threads, sincronização e gerenciamento de recursos.

### Tanenbaum

**TANENBAUM, Andrew S. Sistemas Operacionais Modernos. 3. ed. São Paulo: Pearson, 2009.**

Usar para aprofundar a visão de sistemas operacionais modernos e os mecanismos de gerenciamento de processos e threads.

### Fundamentos de Sistemas Operacionais

[Fundamentos de Sistemas Operacionais — Abraham Silberschatz, Peter Baer Galvin e outros](https://www.kufunda.net/publicdocs/Fundamentos%20de%20sistemas%20operacionais%20(Abraham%20Silberschatz,%20Peter%20Baer%20Galvin%20etc.).pdf)

## 2. Questões selecionadas

### ENADE 2017 — Threads

A questão do ENADE 2017 apresentada neste repositório trabalha criação, execução e sincronização de duas threads com POSIX Threads.

**Fonte:** Indagação

[ENADE 2017 — Criação, execução e sincronização de duas threads](https://www.indagacao.com.br/2023/06/enade-2017-considere-o-programa-seguir-que-ilustra-a-criacao-execucao-e-sincronizacao-de-duas-threads.html)

### ENADE 2017 — Deadlock

A segunda questão trabalha um sistema multithread com duas estruturas de dados e sincronização por semáforos, explorando a possibilidade de ocorrência de deadlock.

**Fonte:** Indagação

[ENADE 2017 — Sistema multithread e estruturas de dados](https://www.indagacao.com.br/2023/06/enade-2017-um-programador-inexperiente-esta-desenvolvendo-um-sistema-multithread-que-possui-duas-estruturas-de-dados-diferentes-el-e-e2.html)
