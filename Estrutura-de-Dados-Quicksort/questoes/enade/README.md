# Questões ENADE

Nenhuma questão do ENADE sobre Quicksort/particionamento pôde ser localizada e verificada diretamente na fonte oficial (prova + gabarito do INEP) no momento da pesquisa para este trabalho. Para não correr o risco de apresentar uma questão inventada como oficial, o requisito de "questão real de prova nacional" foi atendido com uma questão do **POSCOMP** (ver [`../poscomp/poscomp-2019-questao-24.md`](../poscomp/poscomp-2019-questao-24.md)), verificada contra o gabarito oficial da SBC.

## Onde buscar questões oficiais do ENADE
- Portal do INEP — provas e gabaritos do ENADE: https://www.gov.br/inep/pt-br/areas-de-atuacao/avaliacao-e-exames-educacionais/enade/provas-e-gabaritos
- Buscar pela prova de **Computação** do ano desejado.

## Como registrar uma questão real nesta pasta
```markdown
# ENADE — [ANO]

## Questão
Número: XX

## Conteúdo
[Conteúdo abordado]

## Fonte
[Link oficial do INEP para a prova/gabarito]

## Gabarito
[Alternativa]

## Resolução comentada
[Explicação objetiva]

## Conceito cobrado
[Conceito]
```

> ⚠️ Só adicionar uma questão aqui após confirmar o enunciado exato na fonte oficial (PDF da prova do INEP).
